# Carteira-de-Investimentos
Programa em linguagem C, executado no terminal, para cadastrar e acompanhar uma carteira simples de investimentos: calcula o valor atual, a rentabilidade e o lucro ou prejuízo, ordena os ativos por desempenho e apresenta uma simulação educativa.
